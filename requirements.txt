# Памятка по установке и запуску проекта

# 1. Создание виртуальной среды:
# - Убедитесь, что Python версии 3.8 или выше установлен.
# - Выполните в терминале:
#   ```
#   python -m venv venv
#   ```
# - Это создаст виртуальную среду в папке `venv`.

# 2. Активация виртуальной среды:
# - Для Windows:
#   ```
#   venv\Scripts\activate
#   ```
# - Для macOS/Linux:
#   ```
#   source venv/bin/activate
#   ```
# - После активации вы увидите `(venv)` в начале строки терминала.
# - Проверьте, что pip относится к среде:
#   ```
#   pip --version
#   ```
#   Ожидаемый вывод: путь включает `venv`.

# 3. Обновление pip (рекомендуется):
# - Для повышения стабильности установки обновите pip:
#   ```
#   python -m pip install --upgrade pip
#   ```

# 4. Установка зависимостей:
# - Убедитесь, что вы в директории проекта (где находится requirements.txt).
# - Выполните:
#   ```
#   pip install -r requirements.txt
#   ```
# - Это установит pandas, openpyxl, matplotlib, tkcalendar.
# - Проверьте успешную установку:
#   ```
#   pip list
#   ```
# - Убедитесь, что pandas, openpyxl, matplotlib, tkcalendar присутствуют в списке.

# 5. Запуск приложения:
# - Убедитесь, что виртуальная среда активирована.
# - Выполните:
#   ```
#   python main.py
#   ```
# - Приложение PulseBoard Pro запустится.

# 6. Деактивация виртуальной среды:
# - После работы выполните:
#   ```
#   deactivate
#   ```

# Примечание:
# - Если возникает ошибка ModuleNotFoundError, проверьте активацию среды и выполнение шага 4.
# - Для диагностики версий библиотек используйте `pip list`.
# - Убедитесь, что Python версии 3.8+ используется: `python --version`.
# - Если установка не удалась, проверьте подключение к интернету и повторите шаг 4.
